❓ Help & Information

🚀 Getting Started

  • Create a Note: Click "New Note" and fill in the details
  • Add Files: Attach PDFs, documents, or images to your notes
  • Organize: Notes are automatically organized by subject
  • Pin Important: Pin your most important notes
  • Search: Use the search bar to find notes quickly
  • Sort: Sort notes by date or title

💡 Features

  • Smart Tagging: Tags are auto-generated based on content
  • Subject Grouping: View notes by subject category
  • File Support: PDF, DOCX, TXT, and image files
  • Cloud/Local: Works with cloud or local storage
  • Sorting: Sort notes by latest/oldest or alphabetical order

⚙️ Application Mode

Current Mode: LOCAL

This application runs in either LOCAL or CLOUD mode:
LOCAL: Notes stored in SQLite (local computer)
CLOUD: Notes stored in AWS DynamoDB

🎯 Tips & Tricks

  • Use descriptive titles for better searching
  • Pin frequently accessed notes for quick access
  • Use consistent subject names for better organization
  • Attach PDFs of your lecture notes for reference
  • Use the sort feature to organize notes chronologically or alphabetically
